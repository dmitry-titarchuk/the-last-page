# Последняя страница

Браузерный 3D-сокобан: 35 комнат на пяти картах, вступление, процедурная библиотечная мебель, отмена, перезапуск и локальные сохранения.

## Запуск

Нужны Node.js 22 или новее и браузер с WebGL 2.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Каталог моделей: http://127.0.0.1:5173/models.

## Управление и проверки

Стрелки / WASD или свайп — движение. Z — отмена. Мышь или два пальца вверх и вниз — наклон камеры. Меню открывает карты и комнаты.

`npm test` проверяет игровую логику, модели и интерфейсные компоненты. `npm run check:levels` проверяет решаемость комнат.
